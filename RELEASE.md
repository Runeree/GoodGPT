GoodGPT 1.0.4

Исправлено распознавание пустого поля «Работайте с Codex / Work with Codex» в Windows: системная подсказка больше не принимается за черновик. Убрано принудительное отпускание мешка при восьмой конфете. Мешок продолжает следовать за мышью; Escape отменяет ожидающую отправку.

Исправлена вставка в Windows для окон без доступного поля UI Automation. Добавлена отправка через Enter и «Скорректировать / Steer» у собственной похвалы в очереди. Конфеты исчезают при попадании в поле ввода.

Мешочек с угощениями для Codex (ChatGPT) и Claude Code в приложении Claude. Потяните вниз, переверните и высыпьте сладости. После восьми угощений отправится одна фраза похвалы в текущий чат.

## Скачать

- GoodGPT-Windows.exe: переносимое приложение для Windows.
- GoodGPT-macOS.zip: приложение GoodGPT.app для macOS.
- GoodGPT-Chrome.zip: расширение для Chrome, Edge и Chromium.
- GoodGPT-All.zip: все версии и инструкции в одном архиве.
- SHA256SUMS.txt: контрольные суммы файлов.

## Windows

Запустите GoodGPT-Windows.exe и откройте Codex или вкладку Code в приложении Claude. Управление доступно через значок в системном трее.

## macOS

Распакуйте ZIP, перенесите GoodGPT.app в «Программы» и откройте. Разрешите управление приложениями в настройках «Универсального доступа». Откройте Codex или вкладку Code в приложении Claude. Сборка не подписана сертификатом Apple; при первом запуске может понадобиться разрешение запуска в настройках безопасности.

## Chrome

Распакуйте ZIP, откройте chrome://extensions, включите режим разработчика и нажмите «Загрузить распакованное расширение». Выберите папку с manifest.json и обновите страницу ChatGPT.

В версии для рабочего стола отправка зависит от доступности поля сообщения через системные специальные возможности. Похвалу можно отправить во время ответа ИИ через обычную отправку или очередь. Надписи и обводка возле мешка убраны. Черновики и вложения не заменяются. Сборка Windows, синтаксис JavaScript и структура архивов проверены. Живая отправка оставлена для ручной проверки.
