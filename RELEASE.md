GoodGPT 1.1.0

Добавлена версия для Linux: один файл GoodGPT-Linux.deb для Ubuntu и Debian в сеансе X11. Мешок, высыпание угощений, отправка через обычное поле чата и удаление конфет работают без отдельного сервера. Меню открывается правой кнопкой на мешке, надписей и рамки возле него нет.

## Скачать

- GoodGPT-Linux.deb: установочный пакет Linux с зависимостями через apt.
- GoodGPT-Windows.exe: переносимое приложение Windows.
- GoodGPT-macOS.zip: приложение GoodGPT.app для macOS.
- GoodGPT-Chrome.zip: расширение Chrome/Edge для ChatGPT, включая Linux и Wayland.
- GoodGPT-All.zip: все версии с инструкциями.
- SHA256SUMS.txt: контрольные суммы файлов.

## Linux

Скачайте GoodGPT-Linux.deb, откройте терминал в папке с файлом и выполните:

```sh
sudo apt install ./GoodGPT-Linux.deb
```

Запустите GoodGPT из меню приложений. Поддерживаются Ubuntu 22.04 / 24.04 и Debian 12 / 13, X11 с композитингом. Пакет содержит Python-код и подходит для x86_64/ARM64 при наличии системных зависимостей. GTK3, AT-SPI и xdotool устанавливаются через apt. На Wayland используйте расширение для сайта ChatGPT.

Для отправки выбранная сборка Codex/Claude или браузер должны предоставлять поле через AT-SPI. GoodGPT не устанавливает Codex или Claude и не является их Linux-портом. Поддержка конкретного приложения требует ручной проверки. Перед Enter проверяется вставленная похвала; Скорректировать / Steer нажимается только у её новой строки очереди. Черновики и вложения сохраняются. Для вставки временно используется текстовый буфер обмена; его форматирование не сохраняется.

## Windows и macOS

Windows: запустите GoodGPT-Windows.exe. macOS: распакуйте ZIP, перенесите GoodGPT.app в «Программы» и разрешите управление в настройках «Универсального доступа». Готовые приложения не подписаны; версия macOS на Mac не запускалась.

## Браузер

Распакуйте GoodGPT-Chrome.zip, откройте chrome://extensions или edge://extensions, включите режим разработчика и выберите «Загрузить распакованное расширение». Обновите вкладку ChatGPT.

В README добавлены отдельные инструкции установки, управления и удаления Linux-версии. Отправка в настоящие диалоги оставлена для ручной проверки.
