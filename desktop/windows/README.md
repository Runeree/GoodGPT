# GoodGPT для Windows

[Скачать GoodGPT-Windows.exe](https://github.com/Runeree/GoodGPT/releases/latest/download/GoodGPT-Windows.exe)

## Запуск

1. Скачайте `GoodGPT-Windows.exe` и запустите его.
2. Откройте **Codex (ChatGPT)** или **Claude**, выберите в Claude вкладку **Code** и нужную сессию. Мешок появится над активным приложением.
3. Зажмите мешок левой кнопкой и потяните вниз.
4. Удерживая мешок, вращайте колёсико или зажмите Shift и двигайте мышь вбок.

После восьми сладостей GoodGPT сразу пытается отправить одну похвалу. Отпустите мешок для возврата наверх, Escape возвращает его сразу. За одно высыпание бывает одна попытка отправки.

Это переносимый файл для Windows 10/11 со встроенным .NET Framework 4.8. Установка, npm и права администратора не нужны. Приложение не подписано сертификатом издателя. Запускайте GoodGPT и Codex/Claude с одинаковым уровнем прав.

## Меню и отправка

В меню значка GoodGPT в системном трее находятся пауза, возврат мешка, копирование последней похвалы и выход. Повторный запуск не создаёт вторую копию приложения.

Мешок не забирает фокус у чата. Похвалу можно отправлять во время ответа ИИ: используется кнопка отправки, очередь или Enter в поле сообщения. Кнопка остановки ответа не нажимается. Черновики и вложения не заменяются. Возле мешка нет подписей, уведомлений и обводки. Готовую фразу можно скопировать через меню трея.

Распознаются приложения **Codex** и **Claude**, в том числе процессы `Claude.exe`, `claude-code.exe` и `ClaudeCode.exe`. Для Claude Code выберите вкладку Code: GoodGPT использует её обычное поле сообщения. Вкладки за пользователя не переключаются. Совместимость зависит от доступности поля через UI Automation. Текст не отправляется в редакторы исходников. Приложение ChatGPT и сайт ChatGPT в поддерживаемых браузерах также распознаются.

## Сборка

Из корня проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File desktop/windows/build.ps1
```

Используются системный компилятор .NET Framework, WPF и UI Automation. Изображения встроены в EXE. Результат: `dist/GoodGPT-Windows.exe`.

Команда `GoodGPT-Windows.exe --self-check=C:\path\report.json` проверяет чтение встроенных изображений и завершает работу без окон и сообщений. Сборка проверена в Windows; отправка в настоящие диалоги оставлена для ручной проверки.
