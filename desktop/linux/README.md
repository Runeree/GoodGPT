# GoodGPT для Linux

Один файл: [скачать GoodGPT-Linux.deb](https://github.com/Runeree/GoodGPT/releases/latest/download/GoodGPT-Linux.deb).

## Установка

Поддерживаются **Ubuntu 22.04 / 24.04 и Debian 12 / 13**, сеанс **X11** с композитным рабочим столом. Пакет содержит Python-код, поэтому подходит для x86_64 и ARM64 при доступности зависимостей в репозитории дистрибутива.

1. Скачайте `GoodGPT-Linux.deb`.
2. Откройте терминал в папке со скачанным файлом и выполните:

```sh
sudo apt install ./GoodGPT-Linux.deb
```

`apt` установит приложение, GTK3, поддержку доступности и `xdotool`. Для скачивания зависимостей нужен интернет. Не используйте `sudo` для запуска самого GoodGPT.

3. Запустите **GoodGPT** из меню приложений. Также работает команда `goodgpt`.
4. Откройте нужный диалог, дождитесь распознавания окна и потяните мешок вниз. Переворачивайте колёсиком или движением мыши с Shift.

Мешок не показывает надписи и рамку. Правая кнопка на мешке открывает меню с последним состоянием отправки, паузой и выходом. Пауза оставляет мешок доступным для этого меню. После отпускания мешок возвращается наверх. Сладости удаляются при попадании в поле или через несколько секунд.

## Какой чат поддерживается

GoodGPT распознаёт установленные окна с процессом `codex`, `chatgpt`, `claude`, `claude-desktop` или `claude-code`, если они предоставляют поле сообщения через **AT-SPI**. Во вкладке Code приложения Claude заранее выберите нужную сессию. Пакет GoodGPT не устанавливает Codex или Claude и не является их Linux-портом. Наличие этих приложений для Linux и доступность их интерфейса зависят от используемой сборки.

Также распознаётся открытый сайт **chatgpt.com** в Chromium, Chrome, Edge, Brave или Firefox, если браузер передаёт URL документа и поле через AT-SPI. Сайты с другим адресом и обычные редакторы кода не получают ввод.

После восьми угощений выполняется одна попытка отправки. Приложение выбирает пустое поле сообщения, вставляет похвалу и проверяет вставленный текст перед Enter. Во время ответа ИИ нажимается **Скорректировать / Steer** только у строки очереди с этой похвалой. Сообщение может остаться в очереди, когда приложение не предоставляет эту кнопку. Автоматических повторов отправки нет.

Черновики и вложения не заменяются. Для вставки временно используется буфер обмена; предыдущий текст восстанавливается, если пользователь не изменил буфер. Форматирование текста не сохраняется. При нетекстовом содержимом буфера отправка отменяется.

## Если мешок есть, а текст не отправляется

Откройте меню мешка правой кнопкой и прочитайте последнюю причину. Проверьте, что окно чата активно и поле пустое. Включите поддержку специальных возможностей в приложении или браузере. Для Chromium/Electron часто требуется запуск с `--force-renderer-accessibility`; поддержка флага зависит от приложения. Перезапустите приложение после изменения параметров.

Узнать тип сеанса:

```sh
echo "$XDG_SESSION_TYPE"
```

Нужен ответ `x11`. На экране входа выберите сеанс **Ubuntu on Xorg**, **Plasma (X11)** или другой доступный X11-сеанс. Название зависит от рабочего стола. Для прозрачности должен быть включён композитинг.

## Wayland и другие дистрибутивы

Нативная Linux-версия **не поддерживает Wayland**. Она показывает объяснение и завершает работу. Там используйте [GoodGPT-Chrome.zip](https://github.com/Runeree/GoodGPT/releases/latest/download/GoodGPT-Chrome.zip) на сайте ChatGPT: распакуйте архив, откройте `chrome://extensions`, включите режим разработчика и выберите «Загрузить распакованное расширение». Этот вариант работает и в X11.

Для Fedora, Arch и других систем пока нет готового установщика. Исходники открыты, но `.deb` предназначен для Ubuntu/Debian.

## Удаление и сборка

```sh
sudo apt remove goodgpt
```

Сборка пакета из корня репозитория, нужен Node.js 22 или новее:

```sh
npm run desktop:linux
```

Пакет появится в `dist/GoodGPT-Linux.deb`. Для упаковки Linux, `dpkg` и сторонние npm-пакеты не нужны. Графика уже включена. GTK3 и системные зависимости устанавливаются у пользователя через `apt`.

Сборка пакета и логика защит проверяются автоматически. Отправка в настоящие Codex/Claude и работа на конкретном рабочем столе требуют ручной проверки. Приложение не делает сетевых запросов и не собирает телеметрию.
