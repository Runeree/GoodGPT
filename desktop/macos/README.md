# GoodGPT для macOS

[Скачать GoodGPT-macOS.zip](https://github.com/Runeree/GoodGPT/releases/latest/download/GoodGPT-macOS.zip)

## Установка

1. Распакуйте `GoodGPT-macOS.zip` и перенесите `GoodGPT.app` в «Программы».
2. Откройте приложение. Оно не подписано и не прошло нотариальную проверку Apple. Если macOS блокирует запуск, откройте **Системные настройки → Конфиденциальность и безопасность** и используйте действие **Открыть всё равно** для GoodGPT.
3. В строке меню нажмите **GoodGPT → Разрешить управление приложениями**.
4. В разделе **Универсальный доступ / Accessibility** разрешите управление интерфейсом. Процесс может называться `GoodGPT` или `osascript`. После изменения разрешения закройте и снова откройте приложение.
5. Откройте **Codex (ChatGPT)** или **Claude**, выберите в Claude вкладку **Code** и нужную сессию.

Пакет использует встроенные AppKit и JavaScript for Automation. Node.js, Python и Xcode для запуска не требуются. Код рассчитан на macOS 12 и новее, Intel и Apple Silicon.

**Приложение подготовлено в Windows и на настоящем Mac пока не запускалось.** Проверены синтаксис JavaScript и структура ZIP, включая исполняемые права launcher. Работу интерфейса и отправку нужно проверить вручную на macOS.

## Управление

Зажмите мешок левой кнопкой, потяните вниз и переверните колёсиком либо движением мыши с зажатым Shift. После восьми сладостей GoodGPT сразу пытается отправить одну похвалу через поле чата. За одно высыпание бывает одна попытка.

Отпустите мышь, чтобы мешок вернулся наверх. Escape возвращает его сразу. Окно мешка не должно забирать фокус, а прозрачная область пропускает нажатия в другие приложения.

В Codex после вставки нажимается Return, затем кнопка **Скорректировать / Steer** у новой строки очереди с этой похвалой. Конфеты, попавшие в распознанную область ввода, сразу удаляются из физики.

## Доступ к чату

Приложения **Codex** и **Claude** распознаются по bundle ID или имени процесса. Для Claude Code нужно заранее выбрать вкладку **Code**: GoodGPT использует открытое поле её диалога и не переключает вкладки самостоятельно. В редактор исходников текст не вводится. Приложение ChatGPT и сайт ChatGPT в поддерживаемых браузерах также распознаются.

Похвалу можно отправлять во время ответа ИИ: используется обычная кнопка отправки, очередь или Return в поле сообщения. Кнопка остановки не нажимается. Черновики и вложения не заменяются. Буфер обмена восстанавливается после вставки, если пользователь не успел изменить его сам. Автоматического повтора после отправки нет. Подписей и рамки возле мешка нет.

Изменения интерфейса Codex/Claude могут потребовать обновления распознавания. В одном окне с неизменным заголовком не всегда удаётся различить переключение между диалогами; выбирайте нужный чат до снятия мешка.

## Сборка

Из корня проекта, в том числе на Windows:

```sh
npm run desktop:macos
npm run desktop:check
```

Результат: `dist/GoodGPT-macOS.zip`. ZIP сохраняет Unix-права исполнения у `GoodGPT.app/Contents/MacOS/GoodGPT`.

На macOS исходник можно запустить командой:

```sh
osascript -l JavaScript desktop/macos/GoodGPT.js assets
```
